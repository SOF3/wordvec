# Contributing guidelines

## API parity

APIs should try to mimick those in `std::vec` or `smallvec` where applicable,
unless there is an explicit reason to deviate
(e.g. a wordvec-specific performance footgun or design constraint).

## AI policy

- AI tooling is allowed for read-only operations, such as research, diagnosis and review.
- AI assistance in code generation is not allowed,
  except for trivial completion equivalent to LSP-like editor suggestions
  of no more than a few tokens.
  - In particular, AI assistance for bulk boilerplate *generation* is not allowed.
    There are reliable and deterministic tools for that purpose,
    such as vim macros or regex replace.
  - AI-generated doc comment is not allowed,
    with the exception of simple copy-paste from existing code.
- Issues, pull requests, issue/commit comments and PR comments/reviews
  generated by AI tools must be explicitly documented
  (e.g. by placing in a spoiler or by submitting as a bot account).
  Unsolicited AI-generated content is discouraged unless requested by the author or maintainer.
